# Contributing / Contribuer

## English

Bug reports and focused improvements are welcome. Before opening an issue, check whether it already exists. Include the app version, operating system and version, computer architecture, exact steps, expected and actual results, and relevant redacted logs. Never attach Wi-Fi passwords, SSH private keys, access tokens, or an unredacted server log.

For code changes, keep pull requests focused, explain the user-visible effect, and include the checks you ran. Do not claim a platform works based only on a cross-compiled build; report which native machine and workflow you actually used. Disk-writing changes must preserve the operating system's system-drive protections and explicit erase confirmation.

## Français

Les rapports de bug et améliorations ciblées sont les bienvenus. Avant d’ouvrir un ticket, vérifie qu’il n’existe pas déjà. Indique la version de l’application, le système et sa version, l’architecture de l’ordinateur, les étapes exactes, le résultat attendu et obtenu, ainsi que les journaux utiles après suppression des données sensibles. Ne joins jamais de mot de passe Wi-Fi, clé SSH privée, jeton d’accès ou journal serveur non expurgé.

Pour une modification du code, limite la demande, explique son effet visible et indique les contrôles effectués. Une compilation croisée ne suffit pas à affirmer qu’une plateforme fonctionne : précise la machine native et le parcours réellement utilisés. Toute écriture sur un disque doit conserver les protections du disque système et la confirmation explicite d’effacement.
