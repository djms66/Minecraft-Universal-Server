# Security policy / Politique de sécurité

## English

Do not report security vulnerabilities in public issues. Until a private security contact is configured for this repository, contact the maintainer through the email address listed on the GitHub profile `djms66`. Do not include credentials, private keys, Wi-Fi passwords, or personal data in the report. Provide a concise description, affected version, impact, and reproduction steps that do not access another person's data.

## Français

Ne signale pas une faille de sécurité dans un ticket public. Tant qu’un canal privé n’est pas configuré pour ce dépôt, contacte le mainteneur à l’adresse indiquée sur le profil GitHub `djms66`. N’inclus aucun identifiant, clé privée, mot de passe Wi-Fi ni donnée personnelle. Décris brièvement la version touchée, l’impact et les étapes de reproduction sans accéder aux données d’autrui.
